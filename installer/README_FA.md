# نصب‌کننده خودکار SubTube

ساده‌ترین راه راه‌اندازی SubTube: به‌جای ۱۰ قدم دستی با Wrangler، یک اسکریپت
پایتونی روی کامپیوتر **خودتان** اجرا می‌شود، یک توکن API کلادفلر از شما می‌گیرد
و همه‌چیز را خودش می‌سازد.

## اجرا

نیازمندی: فقط Python 3.8 یا بالاتر. هیچ کتابخانه‌ای لازم نیست.

```bash
git clone https://github.com/arshia8058/SubTube.git
cd SubTube
python3 installer/install.py
```

حالت‌های دیگر:

```bash
python3 installer/install.py --dry-run    # فقط نقشه نصب را نشان می‌دهد؛ هیچ تغییری نمی‌سازد
python3 installer/install.py --self-test  # تست آفلاین خود اسکریپت
```

## اسکریپت چه می‌خواهد و چه می‌سازد؟

**از شما می‌گیرد** (ورودی‌ها با getpass گرفته می‌شوند و روی صفحه دیده نمی‌شوند):

| ورودی | از کجا |
|---|---|
| توکن API کلادفلر | اسکریپت یک لینک آماده می‌دهد که توکن را با دسترسی‌های محدود و دقیق می‌سازد |
| توکن ربات تلگرام | از [@BotFather](https://t.me/BotFather) |
| کلید Supadata | supadata.ai (عملاً لازم) |
| کلیدهای Coarena و Gemini | پنل همان سرویس‌ها (اختیاری ولی برای ترجمه لازم‌اند) |

**خودش می‌سازد:**

1. دیتابیس D1 به نام `subtube-db` + اجرای `migrations/schema.sql`
2. فضای KV به نام `SUBTITLE_CACHE`
3. صف `subtube-jobs` + وصل‌کردن مصرف‌کننده‌اش به Worker
4. زیردامنه workers.dev (اگر حساب نداشته باشد، از شما نام می‌خواهد)
5. Worker به نام `subtube-bot` با همه Bindingها و متغیرهای ساده؛ آدرس عمومی
   داخل سورس هم خودکار با آدرس Worker شما جایگزین می‌شود
6. همه سکرت‌ها؛ سکرت وبهوک و توکن دیاگ را **خودش به‌صورت تصادفی** می‌سازد
7. ثبت وبهوک تلگرام (با `callback_query`) و منوی دستورات
8. تست سلامت نهایی و نمایش آدرس ربات آماده

اگر منبعی از قبل وجود داشته باشد (مثلاً اجرای دوباره)، همان قبلی استفاده می‌شود
و چیزی دوباره ساخته نمی‌شود.

## امنیت

- اسکریپت روی کامپیوتر خودتان اجرا می‌شود؛ توکن و کلیدها فقط در حافظه همان
  اجرا هستند و **هیچ‌جا ذخیره، لاگ یا به سرور ثالث ارسال نمی‌شوند**.
  تنها مقصدها `api.cloudflare.com` و `api.telegram.org` هستند.
- کل سورس اسکریپت همین یک فایل است؛ قبل از اجرا بخوانیدش.
- بعد از نصب، اگر خواستید، می‌توانید توکن نصب را از داشبورد کلادفلر باطل کنید؛
  ربات برای کارکردن به آن توکن نیازی ندارد.

## اگر جایی گیر کرد

- **توکن معتبر نیست:** دسترسی‌های توکن را چک کنید (Workers Scripts ،KV ،D1 ،
  Queues به‌صورت Edit و Account Settings به‌صورت Read).
- **مصرف‌کننده صف وصل نشد:** اسکریپت راهنمای دستی‌اش را همان‌جا چاپ می‌کند
  (Queues → subtube-jobs → Consumers → Add consumer).
