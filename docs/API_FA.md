# سرویس‌ها و APIهای SubTube

SubTube خودش هیچ مدل یا سرور جداگانه‌ای ندارد؛ یک Worker است که چند سرویس
بیرونی را به هم وصل می‌کند. این سند همه آن‌ها را بر اساس سورس واقعی فهرست می‌کند.

## ۱) Telegram Bot API

- **آدرس عمومی:** `https://api.telegram.org/bot<TOKEN>/...`
- **کاربرد:** همه ارتباط با کاربر: دریافت آپدیت با وبهوک، ارسال و ویرایش پیام،
  ارسال فایل زیرنویس، دکمه‌های درون‌خطی (Inline Keyboard)، منوی دستورات
  (`setMyCommands`) و دکمه منو (`setChatMenuButton`).
- **متغیر لازم:** `TELEGRAM_BOT_TOKEN` و برای وبهوک `TELEGRAM_WEBHOOK_SECRET`
- **دریافت:** ساخت ربات با [@BotFather](https://t.me/BotFather).
- **دستورات ربات:** `/start` ،`/help` ،`/translate` ،`/status` ،`/cancel` ،
  `/history` ،`/usage` ،`/stats` ،`/about`

## ۲) Supadata — استخراج ترنسکریپت

- **آدرس عمومی:** `https://api.supadata.ai/v1/transcript`
- **کاربرد:** مسیر اصلی استخراج زیرنویس یوتیوب. با حالت `native` و زبان درخواستی
  صدا زده می‌شود؛ اگر پاسخ «در حال پردازش» باشد، با مکانیزم polling (وضعیت ۲۰۲)
  تا آماده‌شدن نتیجه صبر می‌کند.
- **متغیر لازم:** `SUPADATA_API_KEY` (هدر `x-api-key`)
- **دریافت:** ثبت‌نام در supadata.ai؛ پلن رایگان ماهانه دارد.

## ۳) Coarena — موتور ترجمه پیش‌فرض

- **آدرس عمومی:** `https://coarena.ai/api/v1` (سازگار با OpenAI)
- **اندپوینت‌ها:** `POST /chat/completions` برای ترجمه و خلاصه؛ `GET /limits` برای سهمیه (دستور `/usage`).
- **کاربرد:** ترجمه تکه‌های زیرنویس با مدل انتخاب‌شده در دیتابیس
  (در نسخه مرجع: `gemini-4-argon`) و ساخت خلاصه فارسی.
- **متغیر لازم:** `COARENA_API_KEY` و به‌صورت اختیاری `COARENA_API_KEY_2`
  (استخر کلید: خطای ۴۰۱/۴۰۳ یا اتمام سهمیه ۴۰۲ روی یک کلید، یعنی امتحان کلید بعدی).
- **دریافت:** ثبت‌نام در coarena.ai و ساخت کلید از پنل.

## ۴) Google Gemini — موتور ترجمه دوم

- **آدرس عمومی:** `https://generativelanguage.googleapis.com/v1beta/models`
- **اندپوینت‌ها:** `GET /models` (فهرست مدل‌ها، برای عیب‌یابی) و
  `POST /<model>:generateContent` برای ترجمه و خلاصه.
- **کاربرد:** اگر Coarena در دسترس نباشد یا ارائه‌دهنده در تنظیمات روی Gemini باشد.
  ترتیب نامزدهای داخلی کد: `gemini-3.6-flash`، `gemini-3.1-flash-lite`،
  `gemini-3.5-flash-lite`، `gemini-flash-lite-latest`.
- **متغیر لازم:** `GEMINI_API_KEY` (هدر `x-goog-api-key`)
- **دریافت:** Google AI Studio — aistudio.google.com/apikey

## ۵) Google Translate — مسیر پشتیبان ترجمه

- **آدرس عمومی:** `https://translate.googleapis.com/translate_a/single?client=gtx`
- **کاربرد:** اگر یک تکه از زیرنویس از همه موتورهای اصلی رد شود، همان تکه با این
  مسیر ترجمه می‌شود تا فایل ناقص نماند. خطی که این‌جا هم ترجمه نشود، «ترجمه‌نشده»
  حساب می‌شود و در گزارش نهایی پردازش دیده می‌شود.
- **متغیر لازم:** ندارد (اندپوینت عمومی بدون کلید).

## ۶) مسیرهای مستقیم یوتیوب (پشتیبان استخراج)

این‌ها کلید شخصی نمی‌خواهند و فقط وقتی Supadata نتیجه ندهد امتحان می‌شوند:

| مسیر | توضیح |
|---|---|
| Watch Page | خواندن داده پخش‌کننده از صفحه `youtube.com/watch` |
| Innertube Player API | `youtube.com/youtubei/v1/player` با کلاینت‌های ANDROID / iOS / WEB_EMBEDDED (شناسه‌های عمومی کلاینت‌های رسمی یوتیوب؛ کلید شخصی نیستند) |
| Timedtext | `youtube.com/api/timedtext` برای فهرست و متن زیرنویس‌ها |
| Invidious | چند نمونه عمومی (مثل `inv.nadeko.net` و `yewtu.be`) از راه `api/v1/captions` |

## ۷) سرویس‌های خود Cloudflare

| سرویس | کاربرد در SubTube |
|---|---|
| Workers | اجرای کل ربات (fetch + queue handler) |
| Queues | اجرای پردازش‌های طولانی بیرون از وبهوک |
| D1 | ذخیره کاربران، پردازش‌ها، آمار و تنظیمات |
| KV | کش ترجمه و فایل، پیشرفت زنده، انتخاب در انتظار، پرچم لغو |

## قرارداد ترجمه (داخلی)

هر خط زیرنویس با شناسه سراسری خودش به مدل داده می‌شود و مدل باید JSON به شکل
`[{"id": 12, "fa": "متن فارسی"}]` برگرداند. پاسخی که مجموعه شناسه‌هایش دقیقاً
با ورودی یکی نباشد، پذیرفته نمی‌شود. همین قرارداد ساده، ترتیب و زمان‌بندی
زیرنویس فارسی را تضمین می‌کند.
